### 🌟 Featured Engineering Projects

#### 📻 [Spectral Phase Corrector](https://github.com/DanielDobles/Spectral-Phase-Corrector) `Rust` `Math` `DSP`
A micro-phase alignment VST plugin developed in Rust using Fast Fourier Transforms (FFT). It corrects microscopic phase issues in complex multi-microphone setups by rotating the phase at specific frequencies without altering the signal's amplitude or tone.

#### 📊 [Spectral Affinity](https://github.com/DanielDobles/Spectral_Affinity) `Python` `Machine Learning` `Acoustics`
Unsupervised audio clustering system utilizing Convolutional Neural Networks (CNNs) trained on machine listening concepts. It analyzes and indexes hundreds of thousands of audio samples based on harmonic structure, transient density, and emotional vibe.

#### 🧠 [Grimoire](https://github.com/DanielDobles/Grimoire) `TypeScript` `Obsidian` `AI`
Local-first AI agent integration for Obsidian vaults, enabling secure offline LLM-driven semantic indexing, automatic worldbuilding organization, and intelligent data extraction.

#### 🎬 [Pathfindher FW26](https://github.com/DanielDobles/product-design-0-to-hero) `Remotion` `React` `AI Video`
A custom programmatic video pipeline built with Remotion to compile, sequence, and render commercial fashion campaign films dynamically, coordinating pacing, typography, and visual assets via automated JSON configuration.
