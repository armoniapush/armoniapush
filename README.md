### **🌟 Proyectos Destacados (Engineering Projects)**

*   **📻 [Spectral Phase Corrector](https://github.com/DanielDobles/Spectral-Phase-Corrector)** `Rust` `DSP`
    *   *Descripción:* Plugin VST3 de microalineación de fase desarrollado en Rust usando FFT (Fast Fourier Transforms) para corregir desajustes de fase microscópicos en grabaciones de múltiples micrófonos sin alterar el tono.
*   **📊 [Spectral Affinity](https://github.com/DanielDobles/Spectral_Affinity)** `Python` `Machine Learning` `Acoustics`
    *   *Descripción:* Sistema de clasificación no supervisada de librerías de audio mediante CNNs (Redes Neuronales Convolucionales), categorizando muestras por densidad armónica y transitorios.
*   **🧠 [Grimoire](https://github.com/DanielDobles/Grimoire)** `TypeScript` `Obsidian` `AI`
    *   *Descripción:* Integración local de agentes de IA para bóvedas de Obsidian, permitiendo indexación semántica offline, organización y extracción de datos inteligente.
*   **🎬 [Pathfindher FW26](https://github.com/DanielDobles/product-design-0-to-hero)** `Remotion` `React` `AI Video`
    *   *Descripción:* Pipeline programático en Remotion para compilar, secuenciar y renderizar de forma automatizada campañas publicitarias de moda dinámicas mediante configuración JSON.
